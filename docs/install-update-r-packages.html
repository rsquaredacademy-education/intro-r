11  Install & Update R Packages

Learning Objectives: After this chapter you will be able to:

  • Install packages from CRAN, GitHub, Bitbucket, and Bioconductor.
  • Install a specific archived version of a package.
  • List, update, and remove installed packages.
  • Find library paths with .libPaths() instead of hardcoding a path.

11.1 Introduction

In this chapter, we will learn about R packages. Packages are fundamental to R. There are more than 22,000 packages available on CRAN or the Comprehensive R Archive Network (as of September 2026; verify the current count at cran.r-project.org/web/packages).

Packages are available for different topics. You should always look for a package before writing code from scratch. In case you have written your own codes for a new analysis or topic, do share it with the R community by converting the code into a package. You can learn more about building R packages from R Packages, a book written by Hadley Wickham.

11.2 Install Packages

11.2.1 CRAN

Packages from CRAN can be installed using install.packages(). The name of the package must be enclosed in single or double quotes.

install.packages('ggplot2')

11.2.2 GitHub

Some R packages are made available on GitHub before releasing them on CRAN. Such packages can be installed using install_github() from devtools or remotes package. You need to specify the name of the repository and the package. For example, to download ggplot2 or dplyr, below is the code:

devtools::install_github("tidyverse/ggplot2")
remotes::install_github("tidyverse/dplyr")

11.2.3 BitBucket

Bitbucket is similar to GitHub. You can install packages from Bitbucket using install_bitbucket() from devtools or remotes package.

devtools::install_bitbucket("dannavarro/lsr-package")
remotes::install_bitbucket("dannavarro/lsr-package")

11.2.4 Bioconductor

Bioconductor provides tools for analysis and comprehension of high throughput genomic data. Install the BiocManager package and use BiocManager::install():

# install BiocManager if needed
install.packages("BiocManager")

# install a Bioconductor package
BiocManager::install("GenomicFeatures")

11.2.5 rForge

Many R packages are hosted at R-Forge, a platform for development of R packages. (Note: R-Forge is largely inactive today; prefer CRAN or GitHub for new work.)

install.packages('quantstrat', repos = 'https://r-forge.r-project.org/')

For faster installs with dependency resolution, you can also try pak::pkg_install() from the pak package as a modern alternative.

11.3 Install Different Versions

Now that we have learnt how to install packages, let us look at installing different versions of the same package.

remotes::install_version('dplyr', version = 0.5.0)

If you want to install the latest release from GitHub, append @*release to the repository name. For example, to install the latest release of dplyr:

remotes::install_github('tidyverse/dplyr@*release')

11.4 Installed Packages

  • installed.packages(): view currently installed packages
  • library('package_name'): load packages
  • autoload('function_name', 'package_name'): load functions and data from packages only when called in the script
  • available.packages(): packages available for installation
  • old.packages(): packages which have new versions available
  • new.packages(): packages already not installed
  • update.packages(): update packages which have new versions
  • remove.packages('package_name'): remove installed packages

11.5 Library Paths

Library is a directory that contains all installed packages. Usually there will be more than one R library in your system. You can find the location of the libraries using .libPaths().

.libPaths()
[1] "/home/runner/.cache/R/renv/library/intro-r-eca02dad/linux-ubuntu-noble/R-4.5/x86_64-pc-linux-gnu"
[2] "/home/runner/.cache/R/renv/sandbox/linux-ubuntu-noble/R-4.5/x86_64-pc-linux-gnu/46e831e3"

You can use lib when you want to install, load, update and remove packages from a particular library.

11.5.1 Install

install.packages('stringr', lib = .libPaths()[1])

11.5.2 Load

library(lubridate, lib = .libPaths()[1])

11.5.3 Update Packages

update.packages(lib = .libPaths()[1])

11.5.4 Remove Packages

remove.packages('stringr', lib = .libPaths()[1])
